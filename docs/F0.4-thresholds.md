# F0.4 — Đơn vị & Ngưỡng chuẩn

> **TL;DR:** Bảng tham chiếu ngưỡng dùng chung cho Rule Engine, Analyzer và agent reasoning. Mọi quyết định "pass/flag" lấy ngưỡng từ đây — KHÔNG hardcode trong code. Ngưỡng đánh `[tune]` = cần chỉnh sau khi có Standard Set.

---

## 1. Đơn vị nội bộ

Quy tắc duy nhất: **mọi toạ độ và kích thước trong schema đều là device px.** `dpr` lấy từ `screen.viewport.dpr` (tester cung cấp hoặc A13 suy ra).

| Nguồn đầu vào | Quy đổi sang device px |
|---|---|
| Web — CSS px | `value × dpr` |
| Android — dp | `value × dpr` (density = dpr) |
| iOS — pt | `value × dpr` (scale factor = dpr) |
| Ảnh pixel | 1:1 (ảnh đã là device px) |

---

## 2. Touch target

| Nền tảng | Min size | Min gap giữa 2 target |
|---|---|---|
| iOS | 44pt → `44 × dpr` | 8pt |
| Android | 48dp → `48 × dpr` | 8dp |
| Web | 44px CSS → `44 × dpr` | 8px CSS |

Rule: `touch_target_min` → `CMP-03`. Severity nền `high` (range `medium → critical`).

---

## 3. Contrast (WCAG 2.1 AA)

| Loại | Ngưỡng |
|---|---|
| Text thường (< 18pt / < 14pt bold) | ≥ 4.5 : 1 |
| Text lớn (≥ 18pt hoặc ≥ 14pt bold) | ≥ 3.0 : 1 |
| UI component, icon, viền | ≥ 3.0 : 1 |
| "Chữ tàng hình" (cùng màu nền) | < 1.5 : 1 → `critical` |

Nguồn `contrast_ratio` (vision-only): nền đặc → K-means k=2 tách fg/bg → WCAG (`source: "pixel"`); nền ảnh/gradient → `bg_is_solid_px=false`, confidence thấp (`source: "pixel"`).

Rule: `contrast_min` → `STY-01`; `invisible_text` → `STY-02`.

---

## 4. Font size

| Mức | Ngưỡng (device px) | Severity |
|---|---|---|
| Quá nhỏ — không đọc được | < 11px | `high` |
| Nhỏ — cảnh báo | 11–13px | `medium` |
| OK | ≥ 14px | pass |

> 11px device px ≈ 3.67pt@3x ≈ 8pt thực. Áp dụng sau khi nhân `font_scale` (nếu có).

Rule: `font_size_min` → `TYP-05`.

---

## 5. Ảnh & asset

**5.1. Méo tỉ lệ** — `abs(displayed_w/displayed_h − intrinsic_w/intrinsic_h) / (intrinsic_w/intrinsic_h)`

| Mức | Độ lệch | Hành động |
|---|---|---|
| Cảnh báo | > 5% | flag `medium` |
| Lỗi | > 15% | flag `high` |

Rule: `image_distortion` → `IMG-09`.

**5.2. Upscale:** `displayed_w > intrinsic_w × 1.5` → flag `IMG-05` (`medium`).

**5.3. Blur** (Laplacian variance) `[tune]`:

| Mức | Giá trị | Hành động |
|---|---|---|
| Rõ | > 100 | pass |
| Hơi mờ | 50–100 | cảnh báo `low` |
| Mờ | < 50 | flag `medium` |

Áp cho crop của element `role=image`; không áp cho ảnh background trang trí. Rule: A8 → `TYP-09`.

---

## 6. Perceptual hash (A10) `[tune]`

| Mức | Hamming distance (64-bit pHash) | Hành động |
|---|---|---|
| Giống hệt | ≤ 4 bits | flag CONS/LAY dup `high` |
| Gần giống | ≤ 10 bits | flag CONS/LAY dup `medium` |
| Khác nhau | > 10 bits | pass |

---

## 7. Grid & spacing

| Tiêu chí | Ngưỡng | Ghi chú |
|---|---|---|
| Đơn vị grid cơ sở | 8pt/dp/px (sau quy đổi device px) | |
| Sai lệch "lệch grid" | ± 2px `[tune]` | `abs(value mod 8) > 2` |
| Min gap giữa element cùng cấp | 4px | < 4 → ứng viên overlap |
| Overlap đáng kể | iou > 0.05 | flag LAY overlaps |

Rule: `grid_alignment` → `LAY-*`; `overlap` → `LAY-04`.

---

## 8. Off-screen / safe-area

- `offscreen = True` khi `element.bbox` nằm ngoài viewport (bất kỳ phía).
- Vi phạm safe area → flag `ENV-01`:
  - `element.bbox.y < screen.safe_area.top`
  - `element.bbox.bottom > screen.viewport.h − screen.safe_area.bottom`

Rule: `safe_area_violation` → `ENV-01`; `offscreen_element` → `LAY-*`.
