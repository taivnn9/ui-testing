# F0.4 — Đơn vị & Ngưỡng chuẩn

> Bảng tham chiếu dùng chung cho **Rule Engine, Analyzer, Agent**.
> Mọi quyết định "pass/flag" phải dùng ngưỡng từ file này — KHÔNG hardcode trong code.
> Ngưỡng đánh dấu `[tune]` = cần điều chỉnh sau khi có Standard Set.

---

## 1. Đơn vị nội bộ

**Quy tắc duy nhất: mọi toạ độ và kích thước trong schema đều là device px.**

| Nguồn đầu vào | Quy đổi sang device px |
|---|---|
| Web — CSS px | `value × dpr` |
| Android — dp | `value × dpr` (density = dpr) |
| iOS — pt | `value × dpr` (scale factor = dpr) |
| Ảnh pixel | 1:1 (ảnh đã là device px) |

`dpr` lấy từ `screen.viewport.dpr` (tester cung cấp hoặc A13 suy ra).

---

## 2. Touch target

| Nền tảng | Kích thước tối thiểu | Khoảng cách tối thiểu giữa 2 target |
|---|---|---|
| iOS | 44pt → `44 × dpr` device px | 8pt |
| Android | 48dp → `48 × dpr` device px | 8dp |
| Web | 44px CSS → `44 × dpr` device px | 8px CSS |

Rule liên quan: `touch_target_min` → `CMP-03`
Severity nền: `high` (range: `medium → critical`)

## 3. Contrast (WCAG 2.1 AA)

| Loại văn bản / element | Ngưỡng |
|---|---|
| Text thường (< 18pt / < 14pt bold) | ≥ 4.5 : 1 |
| Text lớn (≥ 18pt hoặc ≥ 14pt bold) | ≥ 3.0 : 1 |
| UI component, icon, viền | ≥ 3.0 : 1 |
| "Chữ tàng hình" (cùng màu nền) | < 1.5 : 1 → `critical` |

Nguồn contrast_ratio (vision-only):
- Nền đặc: K-means k=2 tách fg/bg → tính WCAG → `source: "pixel"`
- Nền ảnh/gradient: `bg_is_solid_px=false` → confidence thấp → `source: "pixel"`

Rule liên quan: `contrast_min` → `STY-01`; `invisible_text` → `STY-02`

---

## 4. Font size

| Mức | Ngưỡng (device px) | Severity |
|---|---|---|
| Quá nhỏ — không đọc được | < 11px | `high` |
| Nhỏ — cảnh báo | 11–13px | `medium` |
| OK | ≥ 14px | pass |

> 11px device px ≈ 3.67pt@3x ≈ 8pt thực — dưới mức đọc được trên màn hình thực.
> Ngưỡng này áp dụng sau khi nhân `font_scale` (nếu có).

Rule liên quan: `font_size_min` → `TYP-05`

---

## 5. Ảnh & asset

### 5.1. Méo tỉ lệ (aspect ratio distortion)

| Mức | Độ lệch | Hành động |
|---|---|---|
| Cảnh báo | > 5% | flag `medium` |
| Lỗi | > 15% | flag `high` |

Tính: `abs(displayed_w/displayed_h − intrinsic_w/intrinsic_h) / (intrinsic_w/intrinsic_h)`

Rule liên quan: `image_distortion` → `IMG-09`

### 5.2. Upscale (ảnh vỡ/mờ do phóng to)

```
displayed_w > intrinsic_w × 1.5  →  flag IMG-05  (severity: medium)
```

### 5.3. Blur (Laplacian variance) `[tune]`

| Mức | Giá trị Laplacian variance | Hành động |
|---|---|---|
| Rõ | > 100 | pass |
| Hơi mờ | 50–100 | cảnh báo `low` |
| Mờ | < 50 | flag `medium` |

Áp dụng cho: crop của element `role=image`; không áp cho ảnh background trang trí.
Rule liên quan: A8 Pixel/Glyph Inspector → `TYP-09`

---

## 6. Perceptual hash (A10) `[tune]`

| Mức | Hamming distance (64-bit pHash) | Hành động |
|---|---|---|
| Giống hệt | ≤ 4 bits | flag CONS/LAY dup `high` |
| Gần giống | ≤ 10 bits | flag CONS/LAY dup `medium` |
| Khác nhau | > 10 bits | pass |

---

## 7. Grid & spacing

| Tiêu chí | Ngưỡng | Ghi chú |
|---|---|---|
| Đơn vị grid cơ sở | 8pt/dp/px (sau quy đổi device px) | |
| Sai lệch "lệch grid" | ± 2px device px `[tune]` | abs(value mod 8) > 2 |
| Khoảng cách tối thiểu giữa các element cùng cấp | 4px device px | < 4 → ứng viên overlap |
| Overlap đáng kể | iou > 0.05 | flag LAY overlaps |

Rule liên quan: `grid_alignment` → `LAY-*`; `overlap` → `LAY-04`

---

## 8. Off-screen / safe-area

```
offscreen = True  khi  element.bbox nằm ngoài viewport (bất kỳ phía)
```

Vi phạm safe area:
```
element.bbox.y < screen.safe_area.top               →  flag ENV-01
element.bbox.bottom > screen.viewport.h − screen.safe_area.bottom  →  flag ENV-01
```

Rule liên quan: `safe_area_violation` → `ENV-01`; `offscreen_element` → `LAY-*`
