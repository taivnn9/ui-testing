# F2.0 — Web UI (Upload → Phân tích → Visualize lỗi)

> **TL;DR:** Trang web vanilla (no build step) cho tester: tải ảnh → Phân tích → xem danh sách lỗi + overlay bbox màu theo severity, liên kết 2 chiều list ↔ box. Tái dùng nguyên `POST /analyze`, không đổi backend.
>
> Ngày 2026-06-03. Trạng thái: đã chốt thiết kế, chờ implement.

## 1. Mục tiêu
Giao diện tester: tải ảnh → ấn Phân tích → xem list lỗi + chi tiết → visualize từng lỗi (số thứ tự + khung màu theo severity) ngay trên bản clone của ảnh. Không đổi backend logic.

## 2. Quyết định lớn
- **Stack:** 1 trang HTML/CSS/JS **vanilla**, không Node/build step. FastAPI serve tĩnh cùng service với `/analyze`, deploy 1 phát (zero-config).
- **Visualize:** numbered markers + bbox màu theo severity (Set-of-Marks), liên kết 2 chiều list ↔ box, filter ẩn/hiện theo severity.

## 3. Kiến trúc file
```
src/ui_defect/web/
  ├─ index.html
  └─ static/
      ├─ app.js        # vanilla JS, fetch POST /analyze
      └─ style.css
```
Sửa `src/ui_defect/api/main.py`:
- `from fastapi.staticfiles import StaticFiles` + `from fastapi.responses import FileResponse`
- `app.mount("/static", StaticFiles(directory=<web/static>), name="static")`
- `@app.get("/")` → `FileResponse(<web/index.html>)`
- Resolve đường dẫn qua `pathlib.Path(__file__).resolve()` (chạy đúng dù cwd nào).

Không thêm dependency (StaticFiles có sẵn trong FastAPI).

## 4. Layout giao diện
```
┌───────────────────────── Header ─────────────────────────┐
│  UI Defect Analyzer        [Cài đặt nâng cao ▾]           │
├──────────── Upload bar (drag-drop + nút chọn file) ───────┤
│            [ Kéo-thả ảnh PNG/JPG  hoặc  Chọn file ]       │
│                       [  Phân tích  ]                     │
├───────────────────────┬───────────────────────────────────┤
│  CỘT TRÁI (canvas)    │   CỘT PHẢI (kết quả)              │
│  ảnh + overlay bbox   │   Summary + filter severity       │

└───────────────────────┴───────────────────────────────────┘
```
Responsive: màn hẹp → 2 cột xếp dọc (ảnh trên, list dưới).

### 4.1 Cột trái — Canvas + overlay
> **Cập nhật 2026-06-03:** gom hết bbox lên 1 ảnh gây rối khi nhiều lỗi → mặc định **xem theo từng lỗi**. Có 2 tab:
> - **"Theo lỗi"** (mặc định): full ảnh + chỉ khung lỗi đang chọn. Lỗi không bbox → full ảnh + ghi chú "lỗi toàn màn hình". Caption: "Lỗi ①: <title>".
> - **"Tổng quan"** (phụ): vẽ tất cả khung (Set-of-Marks) + filter severity.
>
> Crop/đổi khung làm client-side (tái dùng ảnh objectUrl), không đổi backend.

- Ảnh upload trong container `position: relative`.
- Mỗi issue có `element_bbox {x,y,w,h}` (device px = kích thước ảnh gốc) → vẽ 1 `<div>` overlay `position:absolute`, scale theo `ratio = displayedWidth / naturalWidth` (tính lại khi resize).
- Mỗi overlay: viền 2px màu severity + badge số thứ tự góc trên-trái.
- Issue không bbox → không vẽ box, vẫn hiện trong list (badge "toàn màn").
- Hover/click box → highlight (đậm viền + glow) + scroll item tương ứng vào view.

### 4.2 Cột phải — Panel kết quả
- **Summary:** tổng số lỗi, dãy đếm theo severity (bấm = filter toggle), confidence_avg.
- **Danh sách lỗi** (sort severity desc, rồi confidence desc): số thứ tự · chấm màu · badge severity · title · confidence.
- Click item → highlight box (2 chiều) + mở rộng chi tiết:
  - `issue_type`, `tags`, `description`
  - `evidence`: `measured_value` vs `expected_value` (nếu có), `element_role`, `element_text`
  - `sources` (vision/pixel) — hiển thị nhỏ.
- Empty state (0 lỗi): "Không phát hiện lỗi 🎉".

### 4.3 Cài đặt nâng cao (collapse, mặc định đóng)
Map thẳng tới Form params của `/analyze`:
- `platform` (select android | ios | web; default android)
- `min_severity` (select trivial…critical; default low)
- `min_confidence` (slider 0–1; default 0.4)
- `agent_backend` (toggle "Chạy agent reasoning"; ON = `codex`/`cline` theo cấu hình, OFF = `none` = rule-only, nhanh)
- Field auto-detect (theme/locale/viewport): không phơi ra UI — hệ thống tự suy (zero-config).

## 5. Luồng dữ liệu
```
User chọn ảnh → preview ngay (chưa gọi API)
  → ấn "Phân tích" → disable nút, spinner "Đang phân tích…"
  → fetch POST /analyze (FormData: screenshot + param nâng cao)
  → nhận AnalyzeResponse JSON → render summary + list + overlay → bật lại nút
```
- `URL.createObjectURL(file)` cho preview & nền canvas (không đợi server trả ảnh).
- `naturalWidth/Height` từ ảnh đã load để tính ratio scale bbox.

## 7. Xử lý lỗi (banner tiếng Việt)
| Tình huống | HTTP | Thông báo UI |
|---|---|---|
| Chưa chọn ảnh, ấn Phân tích | (client) | "Hãy chọn ảnh trước." |
| File > MAX_IMAGE_SIZE_MB | 413 | "Ảnh quá lớn (giới hạn N MB)." |
| File không phải ảnh hợp lệ | 400 | "File không phải ảnh hợp lệ." |
| Pipeline lỗi | 500 | "Phân tích thất bại: <detail>." |
| Mất kết nối / timeout | — | "Không kết nối được server." |
