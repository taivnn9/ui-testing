# F2.0 — Web UI (Upload → Phân tích → Visualize lỗi)

> Spec thiết kế giao diện web cho UI Defect Analyzer.
> Ngày: 2026-06-03. Trạng thái: **đã chốt thiết kế, chờ implement**.

## 1. Mục tiêu
Giao diện web cho tester: **tải ảnh lên → ấn Phân tích → xem danh sách lỗi + chi tiết →
visualize từng lỗi (số thứ tự + khung màu theo severity) ngay trên bản clone của ảnh**.

Không thay đổi backend logic — **tái dùng nguyên `POST /analyze`** đã có.

## 2. Quyết định lớn (đã chốt với user)
- **Stack**: 1 trang HTML/CSS/JS **vanilla**, **không Node, không build step**. FastAPI
  serve tĩnh — cùng 1 service với `/analyze`, deploy 1 phát. Khớp tinh thần zero-config.
- **Visualize**: **numbered markers + bbox màu theo severity** (Set-of-Marks), **liên kết
  2 chiều** list ↔ box (click list highlight box và ngược lại), filter ẩn/hiện theo severity.

## 3. Kiến trúc file
```
src/ui_defect/web/
  ├─ index.html
  └─ static/
      ├─ app.js        # vanilla JS (ES modules ok), gọi fetch POST /analyze
      └─ style.css
```
Sửa `src/ui_defect/api/main.py`:
- `from fastapi.staticfiles import StaticFiles`
- `from fastapi.responses import FileResponse`
- `app.mount("/static", StaticFiles(directory=<web/static>), name="static")`
- `@app.get("/")` → `FileResponse(<web/index.html>)`
- Đường dẫn web resolve qua `pathlib.Path(__file__).resolve()` để chạy đúng dù cwd nào.

Không thêm dependency mới (StaticFiles có sẵn trong FastAPI).

### 4.1 Cột trái — Canvas ảnh + overlay
> **Cập nhật 2026-06-03 (đổi target):** gom hết bbox lên 1 ảnh gây rối khi nhiều lỗi.
> Mặc định chuyển sang **xem theo từng lỗi**: mỗi lỗi 1 ảnh = **full ảnh + đúng 1 khung**
> của lỗi đó. Có **2 tab**:
> - **"Theo lỗi"** (mặc định): hiện full ảnh + chỉ khung của lỗi đang chọn (click ở list).
>   Lỗi không có bbox → hiện full ảnh + ghi chú "lỗi toàn màn hình". Caption: "Lỗi ①: <title>".
> - **"Tổng quan"** (phụ): vẽ TẤT CẢ khung như cũ (Set-of-Marks) + filter theo severity.
>
> Crop/đổi khung làm **client-side** (tái dùng ảnh objectUrl), không đổi backend.

- Hiển thị ảnh upload trong container `position: relative`.
- Mỗi issue có `element_bbox {x,y,w,h}` (đơn vị **device px** = kích thước ảnh gốc) →
  vẽ 1 `<div>` overlay `position:absolute`, scale theo
  **`ratio = displayedWidth / naturalWidth`** (tính lại khi resize window).
- Mỗi overlay: viền 2px màu severity + badge số thứ tự ở góc trên-trái.
- Issue **không có bbox** (vd lỗi toàn màn / nhất quán xuyên màn) → không vẽ box, vẫn
  hiện trong list (badge "toàn màn", không số chỉ vị trí).
- Hover/click box → highlight (đậm viền + glow) và scroll item tương ứng vào view.

### 4.2 Cột phải — Panel kết quả
- **Summary**: tổng số lỗi, dãy đếm theo severity (bấm được = filter toggle), confidence_avg.
- **Danh sách lỗi** (sort theo severity desc, rồi confidence desc): mỗi item gồm
  số thứ tự · chấm màu severity · badge severity · title · confidence.
- Click item → highlight box bên trái (2 chiều) + mở rộng chi tiết:
  - `issue_type`, `tags`, `description`
  - `evidence`: `measured_value` vs `expected_value` (nếu có), `element_role`, `element_text`
  - `sources` (vision/pixel) — hiển thị nhỏ, phụ.
- Empty state (0 lỗi): "Không phát hiện lỗi 🎉".

### 4.3 Thanh điều khiển / Cài đặt nâng cao (collapse, mặc định đóng)
Map thẳng tới Form params của `/analyze`:
- `platform` (select: android | ios | web; default android)
- `min_severity` (select: trivial…critical; default low)
- `min_confidence` (slider 0–1; default 0.4)
- `run_vlm` (toggle "Chạy agent reasoning (Codex)"; default ON. OFF = rule-only, nhanh.
  *Tên param giữ cho tương thích; nay bật/tắt tầng Codex CLI.*)
- (Các field auto-detect như theme/locale/viewport: **không phơi ra UI** — để hệ thống tự
  suy, đúng tinh thần zero-config. Có thể bổ sung sau nếu cần.)

## 5. Luồng dữ liệu
```
User chọn ảnh → preview ngay (chưa gọi API)
  → ấn "Phân tích" → disable nút, hiện spinner "Đang phân tích…"
  → fetch POST /analyze (FormData: screenshot + các param nâng cao)
  → nhận AnalyzeResponse JSON
  → render summary + list + overlay
  → bật lại nút
```
- Dùng `URL.createObjectURL(file)` cho preview & làm nền canvas (không cần đợi server trả ảnh).
- `naturalWidth/Height` lấy từ ảnh đã load để tính ratio scale bbox.
