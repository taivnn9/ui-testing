# F1.1 — Đổi tầng reasoning: VLM → Coding-agent CLI (Codex headless)

> Trạng thái: **ĐANG TRIỂN KHAI** (chốt 2026-06-03). Thay thế hoàn toàn F1.0 (hybrid VLM).
> Lý do đổi: user **không có model multimodal nào hosted** trên vLLM (model text-only báo
> `image input is not supported`). Bỏ VLM, dùng **coding-agent CLI headless** làm tầng lý luận.

## 1. Quyết định lớn (chốt với user)
- **BỎ HẲN VLM / gửi ảnh cho model.** Model chỉ nhận **dữ liệu ký tự** (JSON map + text +
  candidate_issues). Ảnh vẫn được **CV/OCR analyzers** xử lý để TRÍCH map (không gửi cho model).
- Tầng lý luận = **coding-agent CLI headless**:
  - **Codex** (`codex exec`) — có sẵn máy này (đã `codex login`, model `gpt-5.4`).
  - **Cline** — ở máy công ty (cùng giao thức headless; thêm sau qua cấu hình).
- Agent gọi **trực tiếp từ folder project**, có **quyền đọc/ghi file** (`-s workspace-write`).
- Kết hợp **rule (tất định) + skill (file hướng dẫn)** đưa vào prompt cho agent.

## 2. Cơ chế Codex headless (đã smoke-test thật)
```
<prompt qua stdin> | codex exec --skip-git-repo-check --ephemeral \
    -s workspace-write -C <project> [-m <model>] \
    --output-schema <schema.json> -o <out.json> -
→ đọc <out.json> (message cuối) → parse JSON đúng schema
```
- `--output-schema` khóa shape JSON (giải quyết caveat "JSON kém ổn định" của F1.0).
- `-o` ghi message cuối ra file → parse sạch, không lẫn log.
- Smoke: 3 candidate → 8s, ~7k tokens, JSON đúng (confirm/reject + severity + reasoning).

## 3. Pipeline mới (chỉ đổi tầng reasoning; backbone giữ nguyên)
```
Input ảnh PNG
  → Analyzers A0,A3–A13 (CV+OCR)  → schema map (elements/relations)   # vẫn cần ảnh
  → Rule Engine R1–R4             → candidate_issues                  # tất định
  → REASONING (MỚI): Codex exec   ← prompt = (rule candidates JSON + skill files + map text)
       confirm/reject candidate + lỗi text/ngữ nghĩa + severity + reasoning  → findings JSON
  → Critic (dedup + filter)       → summary → API
```
- Không còn `render_som`/ảnh ở tầng reasoning. Code VLM cũ (`llm_client.py`, `g0_framework.py`,
  `prompts.py`) **đã xóa**.
- Vì model không "nhìn" được: nhóm lỗi cần pixel (contrast, ảnh vỡ, font tofu) **đã được CV
  bắt tất định** và đưa vào candidate dưới dạng số/flag → agent lý luận trên số đó, không cần ảnh.

## 4. Thành phần code
| File | Vai trò |
|---|---|
| `agents/codex_client.py` (mới) | Driver `codex exec`: build cmd, stdin prompt, `--output-schema`, đọc `-o`, timeout, lỗi chi tiết. |
| `agents/backends.py` (mới, nhỏ) | Chọn backend qua env `AGENT_BACKEND` (`codex` mặc định; `none` = rule-only). Chỗ cắm Cline sau. |
| `agents/runner.py` (sửa) | Bỏ ảnh/SoM. `run_review(doc)` build prompt text (map + candidates + skills) → gọi backend → parse findings. Giữ `_fill`, `_issues_to_json`, `_parse_findings`. |
| `agents/skills/*.md` (mới) | "Skill" = file tiêu chí theo nhóm (text, layout, color/style, image, components/states, i18n). Driver đọc & nhúng vào prompt. |
| ~~`agents/llm_client.py` / `g0_framework.py` / `prompts.py`~~ | **Đã xóa** (code VLM). |
| `api/pipeline.py` (sửa) | `run_all_agents(doc, img)` → `run_review(doc)` (bỏ img). `mode` = `codex`/`rule-only`. |
| `schema reasoning` | JSON Schema findings (đưa vào `--output-schema`). |

## 5. Cấu hình (env)
```
AGENT_BACKEND=codex        # codex | none(=rule-only)
CODEX_MODEL=               # bỏ trống = mặc định codex (gpt-5.4)
CODEX_SANDBOX=workspace-write   # read-only | workspace-write | danger-full-access
CODEX_TIMEOUT_SEC=180
CODEX_CD=                  # thư mục làm việc (mặc định = repo root)
```
API param `run_vlm` (giữ tên cho tương thích web/API) giờ nghĩa là "chạy tầng agent lý luận".

## 6. Quyền đọc/ghi file
- Agent chạy với `-s workspace-write -C <project>` → đọc/ghi file trong folder project
  (đọc skill files, ghi nháp nếu cần). Tài liệu hóa trong `CLAUDE.md`.
- `.claude/settings.local.json`: cho phép `Bash(codex exec:*)` để khỏi hỏi mỗi lần.

## 7. Lỗi & quan sát (tái dùng cơ chế DEBUG_ERRORS đã có)
- Codex lỗi (timeout/exit≠0/parse fail) → `RuntimeError` chi tiết (cmd + stderr tail) → surface
  vào `pipeline_meta.agent_errors` (degrade graceful: vẫn trả candidate rule, HTTP 200).

## 8. Caveat / phi mục tiêu
- **Cost/latency**: mỗi screenshot = 1 lần `codex exec` (1 call, không phải 6 như VLM cũ) để rẻ.
  Có thể chia nhóm sau nếu cần.
- **Reproducibility**: agent loop không tất định → Standard Set đo trên backbone rule là chính.
- **Cline**: chưa nhúng (ở máy công ty); `backends.py` để sẵn chỗ cắm.
- Không xử lý ảnh ở tầng model (đúng yêu cầu).
