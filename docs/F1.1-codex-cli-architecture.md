# F1.1 — Tầng reasoning: Coding-agent CLI headless (Codex/Cline)

> **TL;DR:** Tầng lý luận đổi từ VLM sang **agent reasoning (Codex/Cline)** chạy headless, text-only — vì user không có model multimodal hosted. Ảnh chỉ dùng ở tầng CV/OCR để trích map; agent chỉ nhận dữ liệu ký tự (JSON map + text + `candidate_issues`).
>
> Trạng thái: ĐANG TRIỂN KHAI (chốt 2026-06-03). Thay hoàn toàn F1.0 (hybrid VLM).

## 1. Quyết định lớn
- **Bỏ hẳn gửi ảnh cho model.** Model chỉ nhận **dữ liệu ký tự**. Ảnh vẫn được CV/OCR analyzers xử lý để trích map (không gửi cho model).
- Tầng lý luận = **coding-agent CLI headless**:
  - **Codex** (`codex exec`) — có sẵn máy này (đã `codex login`, model `gpt-5.4`).
  - **Cline** — máy công ty (cùng giao thức headless; cấu hình thêm sau).
- Agent gọi trực tiếp từ folder project, có quyền đọc/ghi file (`-s workspace-write`).
- Kết hợp **rule (tất định) + skill (file hướng dẫn)** đưa vào prompt.

## 2. Cơ chế Codex headless (đã smoke-test)
```
<prompt qua stdin> | codex exec --skip-git-repo-check --ephemeral \
    -s workspace-write -C <project> [-m <model>] \
    --output-schema <schema.json> -o <out.json> -
→ đọc <out.json> (message cuối) → parse JSON đúng schema
```
- `--output-schema` khóa shape JSON (giải quyết caveat "JSON kém ổn định" của F1.0).
- `-o` ghi message cuối ra file → parse sạch, không lẫn log.
- Smoke: 3 candidate → 8s, ~7k tokens, JSON đúng (confirm/reject + severity + reasoning).

## 3. Pipeline mới (chỉ đổi tầng reasoning; backbone giữ nguyên)
```
Input ảnh PNG
  → Analyzers A0,A3–A13 (CV+OCR)  → schema map (elements/relations)   # vẫn cần ảnh
  → Rule Engine R1–R4             → candidate_issues                  # tất định
  → REASONING (MỚI): codex exec   ← prompt = (candidates JSON + skill files + map text)
       confirm/reject candidate + lỗi text/ngữ nghĩa + severity + reasoning  → findings JSON
  → Critic (dedup + filter)       → summary → API
```
- Không còn `render_som`/ảnh ở tầng reasoning. Code VLM cũ (`llm_client.py`, `g0_framework.py`, `prompts.py`) **đã xóa**.
- Nhóm lỗi cần pixel (contrast, ảnh vỡ, font tofu) **đã được CV bắt tất định** và đưa vào candidate dưới dạng số/flag → agent lý luận trên số đó, không cần ảnh.

## 4. Thành phần code
| File | Vai trò |
|---|---|
| `src/ui_defect/agents/codex_client.py` | Driver `codex exec`: build cmd, stdin prompt, `--output-schema`, đọc `-o`, timeout, lỗi chi tiết. |
| `src/ui_defect/agents/backends.py` | Chọn backend qua env `AGENT_BACKEND` (`codex` mặc định; `none` = rule-only). Chỗ cắm Cline. |
| `src/ui_defect/agents/runner.py` | `run_review(doc)` build prompt text (map + candidates + skills) → gọi backend → parse findings. Giữ `_fill`, `_issues_to_json`, `_parse_findings`. |
| `src/ui_defect/agents/skills/*.md` | "Skill" = file tiêu chí theo nhóm (text, layout, color/style, image, components/states, i18n). Driver nhúng vào prompt. |
| ~~`llm_client.py` / `g0_framework.py` / `prompts.py`~~ | **Đã xóa** (code VLM). |
| `api/pipeline.py` | `run_all_agents(doc, img)` → `run_review(doc)` (bỏ img). `mode` = `codex`/`rule-only`. |
| `schema reasoning` | JSON Schema findings (đưa vào `--output-schema`). |

## 5. Cấu hình (env)
```
AGENT_BACKEND=codex             # codex | none(=rule-only)
CODEX_MODEL=                    # bỏ trống = mặc định codex (gpt-5.4)
CODEX_SANDBOX=workspace-write   # read-only | workspace-write | danger-full-access
CODEX_TIMEOUT_SEC=180
CODEX_CD=                       # thư mục làm việc (mặc định = repo root)
```
API param `agent_backend` (`codex` | `cline` | `none`) bật/tắt & chọn tầng agent; `none` = rule-only.

## 6. Quyền đọc/ghi file
- Agent chạy `-s workspace-write -C <project>` → đọc/ghi file trong folder project (đọc skill files, ghi nháp nếu cần).
- `.claude/settings.local.json`: cho phép `Bash(codex exec:*)` để khỏi hỏi mỗi lần.

## 7. Lỗi & quan sát
Codex lỗi (timeout / exit≠0 / parse fail) → `RuntimeError` chi tiết (cmd + stderr tail) → surface vào `pipeline_meta.agent_errors` (degrade graceful: vẫn trả candidate rule, HTTP 200).

## 8. Caveat / phi mục tiêu
- **Cost/latency:** mỗi screenshot = 1 lần `codex exec` (1 call, không phải 6 như VLM cũ). Có thể chia nhóm sau nếu cần.
- **Reproducibility:** agent loop không tất định → Standard Set đo trên backbone rule là chính.
- **Cline:** chưa nhúng (ở máy công ty); `backends.py` để sẵn chỗ cắm.
- Không xử lý ảnh ở tầng model (đúng yêu cầu).
