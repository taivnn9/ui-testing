# F0.2 — Canonical Schema v1

> Contract dữ liệu chung mà **mọi analyzer ghi vào** và mọi downstream (Rule Engine, Agents)
> đọc ra. Mọi thay đổi schema phải qua version bump.
>
> Toạ độ nội bộ: **device px** (xem F0.4 để quy đổi từ CSS px / dp / pt).

---

## 1. Tổng quan cấu trúc

```
CanonicalDoc
  ├── screen       — meta màn hình & mode vận hành
  ├── image        — đường dẫn + kích thước ảnh gốc
  ├── elements[]   — danh sách phần tử (cây phẳng, quan hệ qua parent/children)
  ├── relations[]  — quan hệ tương đối tiền-tính (overlap, gap, align...)
  └── candidate_issues[]  — output Rule Engine, đưa cho VLM xác nhận
```

## 4. `elements[]`

```jsonc
{
  "id":         "e12",
  "role":       "button | text | image | icon | input | toggle | list | container | tab | nav | modal | skeleton | spinner | divider | unknown",
  "source":     "vision | pixel",       // nguồn chính của element: vision = OCR/CV, pixel = đo từ ảnh
  "confidence": 0.95,                   // [0,1]; 1.0 = độ chắc chắn phát hiện element

  // toạ độ — device px
  "bbox":      { "x": 24, "y": 200, "w": 342, "h": 48 },
  "bbox_norm": { "x": 0.02, "y": 0.08, "w": 0.29, "h": 0.02 },  // / image.w,h

  // cây phân cấp
  "parent":   "e3",          // null nếu là gốc
  "children": ["e13","e14"],
  "z":        2,             // z-order (0 = dưới cùng)

  // text
  "text":          "Thêm vào giỏ",
  "text_truncated": false,

  // style
  "style": {
    "font_size":      16,          // device px (A5 ước lượng từ bbox height)
    "font_family":    "Roboto",
    "color":          "#FFFFFF",   // hex 6 ký tự (A4 đo pixel)
    "bg_color":       "#E53935",
    "contrast_ratio": 4.8,         // tỉ lệ WCAG (A4 tính từ pixel)
    "opacity":        1.0,
    "border_radius":  8,           // device px
    "dark_mode_ok":   true,        // null nếu theme không phải dark; false = hardcode màu sáng

    // ghi đè nguồn ở cấp field — chỉ ghi field nào khác element.source
    "_sources": {
      "contrast_ratio": "pixel",
      "font_size":      "vision"
    }
  },

  // chỉ điền khi role = "image"
  "image_meta": {
    "intrinsic_w":  null, "intrinsic_h":  null,   // luôn null (vision-only, không có DOM)
    "displayed_w":  342,  "displayed_h":  228,    // device px — từ bbox A3
    "scale_mode":   null,                          // không biết object-fit — "unknown"
    "blur_score":   82.4,                          // Laplacian variance (A7); null nếu crop < 32px
    "is_broken":    false,                         // pattern broken-image (A9/A7)
    "is_partial_load": false,                      // ảnh load dở (A9)
    "intrinsic_unavailable": true                  // luôn true ở Phase 1 (vision-only)
  },

  "interactive":    true,
  "touch_target":   { "w": 342, "h": 48 },  // device px (có thể lớn hơn bbox nếu có padding)

  "visible":    true,
  "clipped":    false,   // bị container cắt
  "offscreen":  false,   // nằm ngoài viewport

  "crop": "crops/e12.png"   // null nếu chưa crop
}
```

### 4.1. Enum `role`

| Giá trị | Mô tả |
|---|---|
| `button` | Nút bấm (bao gồm FAB, chip) |
| `text` | Văn bản thuần |
| `image` | Ảnh (img, background-image có nội dung) |
| `icon` | Icon (svg, icon-font, image nhỏ trang trí) |
| `input` | Text field, textarea, search bar |
| `toggle` | Switch, checkbox, radio |
| `list` | List/RecyclerView/FlatList container |
| `container` | Div/View không thuộc loại trên |
| `tab` | Tab item |
| `nav` | Navigation bar, bottom bar, drawer |
| `modal` | Dialog, bottom sheet, toast |
| `skeleton` | Skeleton loading placeholder |
| `spinner` | Loading spinner / progress indicator |
| `unknown` | Không xác định được |

### 4.2. `style._sources` — theo dõi nguồn ở cấp field

Dùng dict `_sources` thay vì nhân đôi field để giữ schema gọn.
Rule Engine / Agent đọc `_sources[field]` để biết độ tin cậy; nếu key không có → dùng `element.source`.

## 5. `relations[]`

Tiền-tính bởi A0 Normalize. Downstream không cần tự suy từ toạ độ thô.

```jsonc
{
  "a":   "e7",
  "rel": "left_of | right_of | above | below | contains | overlaps | sibling",
  "b":   "e8",
  "gap": 8,     // device px; 0 nếu kề nhau; âm nếu overlap (= độ xuyên)
  "iou": 0.0    // intersection-over-union; > 0 nếu có overlap
}
```

**Enum `rel`:**

| Giá trị | Điều kiện |
|---|---|
| `left_of` | a.bbox.right ≤ b.bbox.x (với gap) |
| `right_of` | a.bbox.x ≥ b.bbox.right |
| `above` | a.bbox.bottom ≤ b.bbox.y |
| `below` | a.bbox.y ≥ b.bbox.bottom |
| `contains` | bbox của a bao hoàn toàn b |
| `overlaps` | iou > 0 và không contains |
| `sibling` | cùng parent, không overlap |

## 6. `candidate_issues[]`

Output của Rule Engine. VLM đọc để xác nhận/bác bỏ và bổ sung lỗi cần phán đoán.

```jsonc
{
  "rule":     "touch_target_min",          // ID rule (xem F0.4 + Rule Engine)
  "element":  "e12",                       // element bị dính (null nếu ở cấp màn hình)

  "severity":       "high",               // mức baseline Rule Engine gán
  "severity_range": { "min": "medium", "max": "critical" },  // VLM chốt mức cuối trong range

  "confidence": 0.92,                     // [0,1]; Rule Engine tất định thường = 1.0

  "detail": "touch_target.h=30px < 48dp threshold (144px)",

  "evidence": {
    "bbox": { "x": 24, "y": 200, "w": 342, "h": 30 },
    "crop": "crops/e12.png"
  }
}
```

### 6.1. Severity 5 mức

| Mức | Định nghĩa |
|---|---|
| `critical` | Chặn hoàn toàn: không hoàn thành tác vụ / mất chức năng chính |
| `high` | Nặng: ảnh hưởng rõ tới thao tác & đọc hiểu, vẫn xoay sở được |
| `medium` | Rõ ràng gây khó chịu / giảm tin cậy, không cản trở tác vụ |
| `low` | Nhỏ, phải để ý mới thấy |
| `trivial` | Thẩm mỹ cực nhỏ, gần như bỏ qua được |

> **Lưu ý:** CLAUDE.md §5 cũ dùng 4 mức (`blocker/major/minor/cosmetic`) — đã bỏ.
> Mọi rule và agent phải dùng 5 mức trên.

## 7. Pydantic v2 skeleton

```python
from __future__ import annotations
from typing import Literal, Optional
from pydantic import BaseModel, Field


SourceType = Literal["vision", "pixel"]
PlatformType = Literal["android", "ios", "web"]
SeverityType = Literal["critical", "high", "medium", "low", "trivial"]
RelType = Literal["left_of", "right_of", "above", "below", "contains", "overlaps", "sibling"]
RoleType = Literal[
    "button", "text", "image", "icon", "input", "toggle",
    "list", "container", "tab", "nav", "modal", "skeleton", "spinner", "divider", "unknown"
]


class BBox(BaseModel):
    x: float; y: float; w: float; h: float

class Viewport(BaseModel):
    w: int; h: int; dpr: float

class SafeArea(BaseModel):
    top: int; bottom: int; left: int; right: int

class Screen(BaseModel):
    id: str
    platform: PlatformType
    route: Optional[str] = None
    viewport: Viewport
    safe_area: SafeArea
    theme: Literal["light", "dark", "system"] = "light"
    locale: str = "en-US"
    font_scale: float = 1.0
    ts: Optional[str] = None

class Image(BaseModel):
    full: str; w: int; h: int

class StyleSources(BaseModel):
    font_size: Optional[SourceType] = None
    font_family: Optional[SourceType] = None
    color: Optional[SourceType] = None
    bg_color: Optional[SourceType] = None
    contrast_ratio: Optional[SourceType] = None
    opacity: Optional[SourceType] = None
    border_radius: Optional[SourceType] = None

class Style(BaseModel):
    font_size: Optional[float] = None
    font_family: Optional[str] = None
    color: Optional[str] = None
    bg_color: Optional[str] = None
    contrast_ratio: Optional[float] = None
    opacity: float = 1.0
    border_radius: Optional[float] = None
    dark_mode_ok: Optional[bool] = None   # False = hardcode màu sáng trong dark theme
    sources: Optional[StyleSources] = Field(None, alias="_sources")

class ImageMeta(BaseModel):
    intrinsic_w: Optional[int] = None; intrinsic_h: Optional[int] = None
    displayed_w: Optional[int] = None;  displayed_h: Optional[int] = None
    scale_mode: Optional[Literal["fill","fit","stretch","tile","none"]] = None
    blur_score: Optional[float] = None          # Laplacian variance — A7
    is_broken: bool = False                      # broken-image pattern — A7/A9
    is_partial_load: bool = False                # load dở — A9
    intrinsic_unavailable: bool = False          # luôn True ở Phase 1 (vision-only)

class TouchTarget(BaseModel):
    w: float; h: float

class Element(BaseModel):
    id: str
    role: RoleType
    source: SourceType
    confidence: float = 1.0
    bbox: BBox
    bbox_norm: BBox
    parent: Optional[str] = None
    children: list[str] = []
    z: int = 0
    text: Optional[str] = None
    text_truncated: bool = False
    style: Optional[Style] = None
    image_meta: Optional[ImageMeta] = None
    interactive: bool = False
    interactive_confidence: float = 0.0          # A12: độ chắc [0,1]
    interactive_signals: list[str] = []          # A12: vd ["rounded_rect","action_label"]
    touch_target: Optional[TouchTarget] = None
    visible: bool = True
    clipped: bool = False
    offscreen: bool = False
    crop: Optional[str] = None

class Relation(BaseModel):
    a: str; rel: RelType; b: str
    gap: float = 0.0
    iou: float = 0.0

class SeverityRange(BaseModel):
    min: SeverityType; max: SeverityType

class Evidence(BaseModel):
    bbox: Optional[BBox] = None
    crop: Optional[str] = None

class CandidateIssue(BaseModel):
    rule: str
    element: Optional[str] = None
    severity: SeverityType
    severity_range: SeverityRange
    confidence: float = 1.0
    detail: str = ""
    evidence: Optional[Evidence] = None

class CanonicalDoc(BaseModel):
    screen: Screen
    image: Image
    elements: list[Element] = []
    relations: list[Relation] = []
    candidate_issues: list[CandidateIssue] = []
```

## 8. Ghi chú cho analyzer

- Analyzer **không được ghi thẳng vào `candidate_issues`** — đó là phần của Rule Engine.
- Analyzer chỉ điền `elements[]` (và `relations[]` nếu là A0).
- Field nào không xác định được → để `null`, KHÔNG bịa giá trị.
- `confidence` ở cấp element phản ánh độ chắc chắn của **phát hiện element**,
  không phải của từng field style.
- `source` ở cấp element: `"vision"` khi phát hiện qua OCR/CV; `"pixel"` khi đo trực tiếp từ ảnh.
- Khi một analyzer bổ sung field style cho element đã có → cập nhật field + ghi `_sources`.
