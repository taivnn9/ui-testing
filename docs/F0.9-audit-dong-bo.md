## 🔴 P0 — Bug code (gãy runtime / test đỏ)

### 1. Role `"divider"` không có trong enum → crash pipeline
- `a3_box_layout.py:137-138` trả `role="divider"`, nhưng `RoleType` (`schema/models.py:11`) **không có** `divider`.
- Hệ quả: mỗi khi A3 phát hiện đường kẻ ngang/dọc (aspect ≥ 5) → `ValidationError` khi tạo `Element` → **gãy toàn pipeline trên ảnh thật**.
- Test `test_a3_box_layout::test_divider_detected` đang FAIL vì lỗi này.
- **Giải pháp:** thêm `"divider"` vào `RoleType` + cập nhật schema docs (F0.2) + CLAUDE.md §5. (Hoặc map divider→`container`/`unknown` nếu không muốn role mới — nhưng thêm role rõ ràng hơn.)

### 2. `test_a4_pixel_color::test_black_text_white_bg` FAIL
- `_separate_fg_bg_text` trả fg.mean()==bg.mean()==204 (không tách được fg/bg trên ảnh test 50×20).
- Cần xác định: regression thuật toán hay kỳ vọng test sai. **Giải pháp:** debug `_separate_fg_bg_text` với ảnh test, sửa thuật toán hoặc cập nhật test cho đúng hành vi mong muốn.

### 3. Package chưa cài → `pytest` trần không chạy được
- `tests/conftest.py` import `ui_defect` nhưng chưa `pip install -e .` → `ModuleNotFoundError`. Phải `PYTHONPATH=src` mới collect được.
- `.venv` thiếu `scikit-learn` (A4 có numpy fallback nên không chết, nhưng requirements khai báo) và **không có OCR backend** nào (tesseract/paddle) → R4/G1/G2 không có text.
- **Giải pháp:** chạy `pip install -e ".[dev]"` trong `.venv`; ghi rõ trong SETUP rằng bước này bắt buộc trước `pytest`.
